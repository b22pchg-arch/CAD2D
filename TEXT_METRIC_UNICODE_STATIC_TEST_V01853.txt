FIX3 TEXT METRIC MODEL
- Baseline advance remains AutoCAD 3-on-5 from FIX2.
- Actual MTEXT block height from DWG/DXF is authoritative when available.
- residual = ActualHeight - (lineCount - 1) * LineAdvance.
- The host font is used only for the first-glyph-ascent / last-glyph-descent RATIO.
- That ratio splits the CAD residual above/below the baseline; host em-box no longer determines the absolute DWG attachment rectangle.
- This makes placement content-sensitive for Vietnamese diacritics instead of applying one constant Y shift to all labels.
