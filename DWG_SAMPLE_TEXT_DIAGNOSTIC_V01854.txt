ROOT CAUSE ADDED IN FIX4
A. CAD Height vs host font em-size
- Renderer V0.18.5.3 used font em-size = CAD Height.
- Measurement on the active Arial-compatible renderer gives EmPerCadHeight about 1.423 for the sample.
- FIX4 measures capital H and chooses font em-size so cap-height = CAD Height.

B. MTEXT paragraph alignment
- Raw DWG contains paragraph commands such as \\pxqc;.
- q=c means the paragraph lines are centered in the MTEXT reference rectangle.
- Older parser stripped the whole \\p...; command and lost this information.
- FIX4 extracts alignment first, then strips formatting for plain-text editing.

C. AtLeast line spacing
- First baseline is no longer moved by distributing ActualHeight residual above/below the block.
- For AtLeast, extra ActualHeight is absorbed into baseline-to-baseline gaps.
