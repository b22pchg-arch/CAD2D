DWG Sketch — Hướng dẫn chi tiết Macro Control Center

C# V0.18.18.0 / PWA V0.22.18 · Bao gồm các chức năng Macro từ V0.18.5 đến V0.18.18.

Quan trọng: Tạo Trace và Phát macro là playback thật, không phải dry-run. Với macro có MOVE/COPY/DELETE/biến đổi hình học, nên dùng bản vẽ thử hoặc bản sao.

1. Quy trình khuyến nghị

  1. Chọn hoặc ghi macro.
  2. Thiết lập Input Contract và Source/Target/Reference.
  3. Thiết lập tham số/profile nếu cần.
  4. Chạy Kiểm tra macro (Preflight).
  5. Chạy Tạo Trace.
  6. Kiểm tra RUN/SKIP/FAIL và Result Set.
  7. Khi kết quả đã ổn định, chọn Trace Session và bấm Đặt Baseline.
  8. Các lần chạy sau được Auto Compare với Baseline.

2. Library Organizer

Chức năngCách dùng
TìmTìm theo tên, ID, Category hoặc Tag.
Nhóm/TagGán Category và nhiều Tag để phân loại macro.
FavoriteĐánh dấu macro thường dùng và lọc Favorites.
Nhân bảnTạo macro mới từ macro hiện tại, cấp StepId mới và reset thống kê chạy.

3. Ghi và phát macro

Bắt đầu ghi → thực hiện các lệnh được hỗ trợ → Dừng & lưu. Phát macro dùng engine thật, thực thi theo step đã bật, input binding, branch và output role.

4. Parameter Profiles

Nhập tham số dạng NAME=value; NAME2=value. Profile cho phép lưu/nạp nhanh bộ tham số cho cùng macro.

5. Input Contract và Runtime Roles

Input Contract xác định loại và số lượng input tối thiểu. Runtime roles gồm Source, Target, Reference. Chọn đối tượng trên bản vẽ rồi bấm Gán tập chọn vào role.

6. Result Sets

Result/Result1/Result2/Result3 là derived outputs được sinh trong playback. Chúng tự xóa trước mỗi lần chạy để tránh dữ liệu stale. Relative step có thể publish vào Result Set hoặc Target.

7. Step Editor

Mỗi step có StepId ổn định, Action, Arguments, Enabled, Input Role, Reference Role, Output Role, Condition, Branch Mode/Group. Có thể lưu, lên/xuống, bật/tắt và xóa step.

8. Relative Geometry

RMOVE/RCOPY/RROTATE/RSCALE/RMIRROR dùng vector/pivot/trục tương đối. Reference Anchor hỗ trợ 9 điểm: bốn góc, bốn trung điểm cạnh và Center; giúp macro thích nghi tập chọn có kích thước/vị trí khác.

9. Branch Conditions

Hỗ trợ Always, Exists/Missing, Count AtLeast/AtMost/Equals và Kind Overlay/CAD/Mixed. Condition false ghi SKIP thay vì lỗi.

10. BranchGroup Case/Else

Independent chạy độc lập. Case hoạt động theo first-match trong cùng BranchGroup. Else là fallback khi chưa Case nào match.

11. Preflight

Kiểm tra macro xác minh Input Contract, role binding, thứ tự Result chain, branch syntax/group. Đi tới bước lỗi đưa Step Editor tới lỗi được xác định.

12. Macro Trace

Trace ghi từng step: RUN, SKIP, SKIP_DISABLED, SKIP_UNSAFE hoặc FAIL; kèm Branch/Condition/Input/Output. Double-click dòng Trace để tìm step theo StepId.

13. Trace History — Test Bench

Mỗi lần Phát macro/Tạo Trace lưu một Trace Session. History tối đa 50 phiên, có thể Nạp phiên, Xuất JSON, Xóa phiên, Xóa lịch sử. C# lưu ở %LOCALAPPDATA%\DwgSketchPrototype\macro-trace-history-v1.json; PWA lưu localStorage.

14. Regression Baseline + Compare Trace — V0.18.18

Mới: chọn một Trace Session đã được xác nhận làm Baseline. Từ lần chạy kế tiếp, phần mềm tự động so sánh Trace hiện tại với Baseline.
NútTác dụng
Đặt BaselineĐánh dấu phiên đang chọn làm chuẩn của macro. Phiên hiện ★ BASE.
So sánh phiênSo sánh thủ công phiên đang chọn với Baseline cùng MacroId.
Xuất Diff JSONXuất report gồm session IDs, revisions, PASS/FAIL và danh sách differences.
Bỏ BaselineGỡ chuẩn của macro nhưng không xóa Trace Session.

Compare dùng StepId làm khóa. Các loại Diff: ADDED, REMOVED, ACTION, STATE, BRANCH, IO, FAIL_DETAIL, RESULT.

RESULT so sánh chữ ký của Result/Result1/Result2/Result3 theo dạng total|overlayCountO|cadCountC. Vì vậy có thể phát hiện output thay đổi dù tất cả step vẫn RUN.

Nếu revision macro thay đổi nhưng hành vi Trace/Result vẫn giống Baseline, summary chỉ báo revision thay đổi; Regression vẫn có thể PASS.

15. Cách xây Baseline đáng tin cậy

  1. Dùng bản vẽ test đại diện.
  2. Gán đúng roles.
  3. Preflight PASS.
  4. Chạy Trace ít nhất một lần và kiểm tra kết quả hình học/Result.
  5. Chỉ bấm Đặt Baseline khi phiên đó được xác nhận là đúng.
  6. Sau khi sửa macro, chạy lại nhiều bộ input để Regression phát hiện sai lệch.

16. Tương thích dữ liệu
