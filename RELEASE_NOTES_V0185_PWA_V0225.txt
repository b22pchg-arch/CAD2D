MACRO ENGINE PHASE 1 + VERSIONED LIBRARY CATALOG
Release date: 2026-08-09

1. MACRO ENGINE PHASE 1
- Ghi va phat lai chuoi lenh CAD duoc danh dau replay-safe.
- Khong ghi cac lenh can bam diem, keo chuot hoac mo hop thoai de tranh phat sai ngu canh.
- Chuan hoa alias sang action canonical de tang kha nang trao doi macro C# <-> PWA, vi du:
  SELECTALL -> ALL; DEL -> DELETE; FILL -> SOLID; H -> HATCH; BX -> BEXPLODE;
  SELFRAME -> SELF; F8 -> ORTHO; CURSOR/CONTROR -> CROSSHAIR; OS/SNAP -> F4;
  ZALL/ZOOMALL/ZOOMEXTENTS/FIT -> ZA.
- BLOCK/B bi loai khoi replay-safe vi can hop thoai dat ten.
- Macro co Id, Name, Version, Revision, UpdatedAt, Parameters (du phong Phase 2) va Steps.
- Khi luu de cung Id, Revision tu tang.
- Macro co buoc DELETE/BEXPLODE/B2SYM yeu cau xac nhan truoc khi phat.
- C# luu tai LocalAppData/DwgSketchPrototype/cad-macros-v1.json.
- PWA luu tai localStorage DwgSketchPwa.CadMacros.V1.
- Ho tro import/export JSON schema dwg-sketch-cad-macros, schemaVersion 1.
- Lenh: MACROREC, MACROSTOP, MACROPLAY, MACRODELETE, MACROIMPORT, MACROEXPORT.

- C# mirror collection active ve storage thu vien cu de giu tuong thich nguoc.
